## 已确定范围

- 一级导航：设备 / Data / 信息。Data 位于中间，使用数据库图标。
- 设备切换：左上角设备名称与箭头进入独立列表页，多设备纵向滚动；不展示添加设备和保存设备说明，不因切换自动连接 Wi-Fi。
- 添加设备：先进入添加页，蓝牙关闭时在搜索区域提示；发现多个设备支持左右滑动，至少两台同屏。
- 设备相册、预览和设置：先校验当前设备 Wi-Fi 与身份，成功继续原入口；取消和失败不进入设备功能。
- 设备相册分类为视频 / 紧急 / 图片；隐藏抓拍，不增加设备相册地图和列表通道筛选。预览、相册、时间轴与回放仅参考指定 Figma 关键页的布局和控件。
- App 主页面白底，确认弹窗居中、左右操作按钮，遮罩覆盖整个手机界面。时间轴操作区按 Figma 保持深色。
- 设置退出回来源页，恢复反馈在来源页呈现；无独立恢复录像页。设置项与候选值均为示例，实际由设备返回，红字说明保留在页外。
- App Update 留在信息页：检查中为 Loading Toast，有新版本为居中弹窗，无新版本或失败为 Toast，不恢复独立更新页。

## 关键验收条件

### 分享片段

1. 片段开始不小于 0，时长大于 0，结束不超过源视频，时长不超过 60 秒。开始位置变化导致越界时同步缩短时长。
2. 小于 1 秒的视频按实际支持精度处理，不强制扩大为 1 秒。原型提供 0.5 / 30 / 60 / 180 秒评审样例；0.1 秒步长不等于已承诺的编码精度。
3. 生成时锁定重复提交和选段操作；取消或离页后旧回调不能打开分享面板。失败保留选段，可重试。
4. 空间不足的分享任务回 F03；设备录像下载回 D04 / D05。管理本地文件后回 X05，不丢失来源。
5. 原文件不变，生成有效副本后才调用系统分享。转交第三方不代表发布成功。真实源时长、输出质量、码率估算与编解码器由 App 接入验证。

### 离线地图

1. 区域、大小与版本来自现版 SDK / 服务；同一完整版本不重复下载，新版本可更新。
2. 网络、空间、校验失败分别提示并重试；失败或取消不标记完成，更新失败保留旧有效版本。
3. 删除需确认，仅删除选定本地地图包；取消不变，删空显示空态。完整地图不受通用清缓存影响。
4. 原型切页或关闭后取消未完成演示，已完成状态保留。正式后台与恢复行为依 SDK；删除失败不得提前移除记录。
5. 不将离线地图下载完成解释为记录仪已连接、Data 已安装或所有 GPS 轨迹可离线显示。

### 录像和升级

1. 进入设置前读取录像状态，未知时先查询；需要停录时仅在确认命令成功后进入设置。原本停录的设备退出设置后仍停录。
2. 本流程停录的设备退出后在来源页恢复，成功依据实际状态。失败显示恢复入口，不显示虚假的 REC。
3. 固件包先校验型号、硬件、版本和完整性，再连接目标设备传输。接收成功不等于安装成功。
4. 下载阶段可停止本地获取；传输与安装阶段的可取消点依固件协议，不把关闭界面等同于设备停止任务。
5. 断连后先查任务阶段，再决定等待或重试；未确认设备可安全重传时不自动重复提交。重连原设备并核验目标版本后才显示成功。

## 机型能力表填写规范

每个实际销售型号和适用固件版本独立填写以下表项；原型中的型号只是样例，不代表已确认支持列表。

| 字段 | 需要记录的内容 | 未知时的页面行为 |
|---|---|---|
| 型号 / 固件 / 硬件 | 真实标识、适用版本、默认 SSID 规则与认证方式 | 身份未核验时禁止发送控制命令 |
| 蓝牙发现 | 是否支持、广播标识、权限与扫描协议 | 保留手动连接，不把未知能力当作不支持 |
| 通道 | 通道数量、标识、当前在线状态 | 确认不支持才隐藏；支持但离线显示通道异常 |
| 设置 | 字段、类型、候选值、当前值、关联依赖 | 读取失败提供重试，不写入示例默认值 |
| 录像控制 | 查询 / 开始 / 停止、确认回包与幂等规则 | 状态未知先查询，不显示伪成功 |
| 媒体与 GPS | 文件标识、时区、分类、下载及 GPS 能力 | 无 GPS 隐藏轨迹，读取失败不伪造数据 |
| 固件升级 | 包匹配、分阶段状态、恢复及安全重试能力 | 仅开放能力已确认的流程 |

由 App / 固件提供上述真实值并关联接口或协议版本。本次不填入无来源的支持/不支持结论。
